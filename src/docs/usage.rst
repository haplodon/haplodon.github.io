.. _usage:

*****
Usage
*****

Run haplodon from the command line using the following syntax:

.. code-block:: bash

    haplodon <command> [options]

Use ``haplodon --help`` for general help, or ``haplodon <command> --help`` for the details of a
specific command. All commands accept ``--verbose``/``-v`` for logging and ``--threads``/``-t`` for
multi-threaded execution (defaults to all available logical cores).

Build
~~~~~

Builds a full variant graph from VCF files and stores it.

**Options:**

- ``--calls <path>``: Path to the VCF calls file.
- ``--observations <sample=observations.vcf>``: One or more varlociraptor observation files; the sample names must match those in the calls file.
- ``--min-prob-present <float>``: Minimum probability for a variant to be considered in the graph. Defaults to ``0.8``.
- ``--min-vaf <float>``: Minimum VAF for a variant to be kept; the maximum VAF across samples must meet or exceed this. Defaults to ``0.05``.
- ``--output <path>``: Path to store the generated variant graph.

**Example:**

.. code-block:: bash

    haplodon build --calls calls.vcf --observations sample1=obs1.vcf sample2=obs2.vcf --output graph.duckdb

Process
~~~~~~~

Retrieves subgraphs for individual features from the given GFF file and calculates scores for all
haplotypes of each transcript.

**Options:**

- ``--features <path>``: Path to the GFF file containing the features of interest.
- ``--reference <path>``: Path to the reference genome FASTA file.
- ``--graph <path>``: Path to the graph file generated by the build command.
- ``--distance-metric <string>``: Amino acid distance metric. One of ``grantham``, ``sneath``, ``epstein`` or ``miyata``. Defaults to ``grantham``.
- ``--haplotype-metric <string>``: Metric to aggregate variant VAFs into a haplotype frequency. One of ``product``, ``geometric-mean`` or ``minimum``. Defaults to ``minimum``.
- ``--max-haplotypes-per-transcript <int>``: Maximum number of haplotypes to consider per transcript, ranked by minimum read support across edges. Defaults to ``50``.
- ``--genebe-cache <path>``, ``--genebe-email <str>``, ``--genebe-api-key <str>``, ``--genome-build <hg38|hg19|t2t>``: GeneBe annotation options.
- ``--output <path>``: Path to the output file storing the calculated scores.

**Example:**

.. code-block:: bash

    haplodon process --features features.gff --reference reference.fasta --graph graph.duckdb --output scores.duckdb

Peptides
~~~~~~~~

Extracts distinct peptide sequences for each feature in the provided GFF file and writes them to a
FASTA file.

**Options:**

- ``--features <path>``, ``--reference <path>``, ``--graph <path>``: as above.
- ``--interval <start-end>``: Peptide length interval. Defaults to ``8-11``.
- ``--sample <str>``: Sample name used to retrieve allele frequencies from the graph.
- ``--events <list>`` / ``--min-event-prob <float>``: Events of interest and the minimum peptide probability threshold.
- ``--background-events <list>`` / ``--max-background-event-prob <float>``: Background events and their maximum probability.
- ``--output <path>``: Path to the output directory for the FASTA files.

**Example:**

.. code-block:: bash

    haplodon peptides --features features.gff --reference reference.fasta --graph graph.duckdb --sample sample1 --events event1 --min-event-prob 0.8 --background-events event2 --max-background-event-prob 0.2 --output peptides/

Plot
~~~~

Outputs the calculated scores as a single TSV file with columns ``transcript``, ``score``,
``haplotype``, the annotation score columns, and per-sample frequency and supporting-read columns.

**Options:**

- ``--input <path>``: Path to the data file generated by the process command.
- ``--notation <string>``: Haplotype notation. One of ``hgvsg``, ``hgvsc`` or ``hgvsg-full``. Defaults to ``hgvsg``.
- ``--report-protein``: Additionally output the reconstructed protein sequence column.
- ``--output <path>``: Path to the output TSV file.

**Example:**

.. code-block:: bash

    haplodon plot --input scores.duckdb --output scores.tsv

Example workflow
~~~~~~~~~~~~~~~~~

.. code-block:: bash

    # 1. Build the variant graph
    haplodon build --calls calls.vcf --observations sample1=obs1.vcf sample2=obs2.vcf --output graph.duckdb

    # 2. Process the graph with a GFF file
    haplodon process --features features.gff --reference reference.fasta --graph graph.duckdb --output scores.duckdb

    # 3. Write the per-transcript scores
    haplodon plot --input scores.duckdb --output scores.tsv
