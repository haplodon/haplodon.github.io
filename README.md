# haplodon.github.io

Documentation for [haplodon](https://github.com/fxwiegand/haplodon), built with
[locosopa](https://github.com/koesterlab/locosopa) and deployed to
[haplodon.github.io](https://haplodon.github.io).

The content lives in `src/` (`config.yaml` and the `docs/` reStructuredText files).
